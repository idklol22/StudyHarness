# T06 — MCQs and flashcards only when the user asks

## Goal
In plain study chats the agent must not volunteer MCQs or flashcards; when the user explicitly asks for them it must supply them in full in its reply. Prompt-text change only.

## Files to change
- `src/agent/study-chat-prompt.md` — add one paragraph after line 3 (below the course-files paragraph, above `show_figure`).
- `tests/study-chat-prompt.test.ts` — extend the file created by T01 (build T01 first); do not create a second test file.

## Scope decision (read before editing)
Teach/practice chats are deliberately out of scope: `src/core/study/doctrine.ts:42` (`CARDS`) is a documented core feature ("Flashcards the tutor adds while teaching", README:47) and its quiz tools are the teaching method. The prohibition belongs in the plain study-chat prompt — the only prompt covering free-form questions outside a lesson. Do not touch doctrine or tool gating.

## Data / API shape
No API or storage change; same single-string system prompt as T01. Plain-chat tool registry already excludes `quiz`, `study_cards`, `study_practice_next` and `study_practice_rate` (`src/agent/tools/study.ts:269-272`, pinned by `tests/study-agent.test.ts:148-155,167-183`), so "give them" means **write them in the reply as Markdown**, not create stored cards. No tool changes.

Exact text to append after line 3:
`Do not volunteer multiple-choice questions or flashcards. Create them only when the user explicitly asks for an MCQ, quiz or flashcards. When they do ask, always give the full set requested in your reply: MCQs with labelled options and an answer key, flashcards as short question/answer pairs. Never offer to make them instead of making them.`

## UI/UX design
N/A — no component, layout or theme change. No tokens, px, positions, z-index or keyboard behaviour involved. The rendered MCQ/flashcard Markdown uses the existing chat prose styles unchanged.

## Edge cases
- "quiz", "MCQ", "multiple choice", "flashcard"/"cards" as explicit request words trigger the always-give rule; a bare mention while discussing course content does not force a quiz into an unrelated answer.
- Asked for 5 cards → give 5, not a sample plus an offer. No hedging, no "I can if you'd like".
- If the user attached files, keep the cite rule from line 3; the MCQ/card content still comes from the answer, not from fabricated citations.
- Applies only to plain study chats (`chat-handler.ts:258`). Side questions use their own brevity prompt and are unaffected.
